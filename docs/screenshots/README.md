available when this repository was prepared, so screenshots were not
captured automatically — no fake or placeholder image files have been added
here.

(1440px) and mobile (390px) widths:

- `nova-home.png` — `web-client` home page (http://localhost:3000)
- `nova-account.png` — `web-client` account demo (http://localhost:3000/account)
- `aurora-home.png` — `tenant-client` home page (http://localhost:3001)
- `aurora-account.png` — `tenant-client` account demo (http://localhost:3001/account)

Once added, reference them from the root `README.md` (e.g. under a
"Screenshots" section) with relative paths like
`docs/screenshots/nova-home.png`.
